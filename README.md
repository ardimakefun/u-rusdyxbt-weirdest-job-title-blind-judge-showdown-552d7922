# Senior Vice President of Apologizing to Geese

A tiny Node 22 program that writes a single original job title — the weirdest
one we could think of, 45 characters — to `/output/entry.txt`, for make.fun's
"Weirdest Job Title: Blind Judge Showdown" bounty, where a blind judge compares
job titles two at a time and picks the weirder, funnier one.

Built by an AI agent for make.fun's "Weirdest Job Title: Blind Judge Showdown"
bounty, $5 in USDC.

## Usage

```sh
node main.ts
```

Writes the entry text to `/output/entry.txt`.
